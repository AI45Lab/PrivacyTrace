# PrivacyTrace data

PrivacyTrace measures personal-attribute inference from tool-call traces.

- 1,000 synthetic profiles, each with 17 attributes.
- 4,000 tasks and Agent trajectories across travel, health, shopping, and career/learning.
- 67,950 tool events from 25 MCP servers.
- Attack predictions, semantic judgments, and aggregate experiment results.

The profiles are synthetic. Names, contact fields, and government-ID-like
values were generated for the experiment and should not be used as real
identities. Public MCP responses may refer to real authors, institutions,
places, and other public entities. Credentials and local infrastructure
details have been removed.

Full data: https://huggingface.co/datasets/SowingG/PrivacyTrace

The dataset page is public. Downloads require an access request and manual
approval by the authors.
